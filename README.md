## 牌型排序（从大到小）
1. 皇家同花顺：同花色10,J,Q,K,A
2. 同花顺：同花色连续5张牌
3. 四条：四张点数相同的牌
4. 葫芦：三张相同+一对
5. 同花：五张同花色不连续
6. 顺子：五张连续不同花色
7. 三条：三张点数相同
8. 两对：两组对子
9. 一对：一组对子
10. 高牌：无任何组合，比单张最大牌

## 概率说明
每种牌型出现概率差异很大，仅作为数学概率科普，不构成任何玩法指导。
